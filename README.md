# TopoFault

Implementation of **Netlist-aware graph-waveform alignment for analog soft-fault localization**.

## Installation

Requires Python `>=3.11`. Run from the repository root in an activated environment.

```bash
python -m pip install -e .
```

Inspection environment: Python 3.13.5; numpy 2.1.3, scipy 1.15.3, torch 2.7.1+cu118, torchvision 0.22.1, scikit-learn 1.6.1, matplotlib 3.10.0, pillow 12.3.0. Checks: Python syntax, configuration parsing and CLI/source argument matching. Training and full evaluation were not run.

## Data and preprocessing

Supply existing SPICE Monte Carlo responses or export responses generated by ngspice; the circuit simulator/exporter is external to this repository. Group every tolerance realization by circuit, injected component and signed drift before splitting.

`x` and `x_pair` are float32 [N,4,T] with AC magnitude, unwrapped AC phase, transient voltage and transient difference resampled onto a fixed normalized grid. `node` is [N,V,F], `adjacency` [N,V,V], `y` zero-based component index, `severity` signed drift and `group` fault-setting ID. Use separate configurations for circuits with different V.

```bash
python -m topofault prepare --source data/raw.npz --output data/prepared --seed 17
```

Use `group` to keep every derived view of one source object in the same partition. An explicit integer `split` array (0=train, 1=validation, 2=test) preserves a registered split. Otherwise groups are assigned 60/20/20. Every stored field must share the sample axis. Files are loaded without pickle.

## Training and inference

Set input dimensions, device, training budget and `seed` in `configs/default.json` (default seed 17).

```bash
python -m topofault train --config configs/default.json --data data/prepared --output runs/main
```

## Evaluation

```bash
python -m topofault evaluate --checkpoint runs/main/topofault/model.pt --data data/prepared/test.npz --output results/topofault
```

## Ablations

```bash
python -m topofault suite --config configs/default.json --data data/prepared --output runs/comparison
```

Select a subset with `--methods`: `topofault`, `waveform_only`, `graph_only`, `late_fusion`, `no_consistency`, `no_severity`, `no_calibration`.

## Outputs

`runs/main/topofault/model.pt` stores the validation-selected weights, method and configuration; `history.jsonl` records measured epoch losses and time. Evaluation writes `predictions.npz` and `metrics.json` under `results/topofault`.

```bash
python -m topofault plot --inputs runs/main/topofault results/topofault --output figures
```

`figures/` contains loss curves and metric plots from the supplied run directories.
